## النشر (Cloudflare + GitHub)

المشروع مربوط بـ **GitHub** للكود و**Cloudflare Workers/Pages** للنشر (انظر `wrangler.jsonc`).

```bash
npm run build
npm run deploy
```

أضف متغيرات البيئة في لوحة Cloudflare:

- `NEXT_PUBLIC_GOOGLE_CLIENT_ID` — لمزامنة Google (اختياري)
- `NEXT_PUBLIC_ADMIN_EMAIL` — بريد الأدمن (داخلي، لا يظهر للمستخدمين)
- `NEXT_PUBLIC_ADMIN_INITIAL_PIN` — رمز دخول الأدمن الافتراضي (يُطبَّق مرة واحدة)

> ملف `netlify.toml` بقي من إعداد سابق و**ليس مطلوباً** إذا كنت تستخدم Cloudflare فقط.

## رمز الأدمن (PIN)

1. افتح `/admin` في التطبيق
2. أدخل الرمز من `NEXT_PUBLIC_ADMIN_INITIAL_PIN` (الافتراضي في التطوير: `284719`)
3. يمكنك تغييره لاحقاً من لوحة الأدمن

## العملات وأسعار الصرف

من **الإعدادات → عام**:

- اختر **العملة الأساسية** (للمجاميع والميزانية)
- فعّل عملات إضافية
- أدخل **سعر الصرف** لكل عملة فرعية (مثال: 1 USD = 50 EGP)

عند إضافة مصروف، اضغط رمز العملة بجانب السعر للتبديل.  
**تغيير سعر الصرف يطبّق على المشتريات الجديدة فقط** — الصفوف القديمة تحتفظ بالسعر وقت إضافتها.
