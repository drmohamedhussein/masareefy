# مصاريفي (Masareefy)

إضافة ووردبريس لتتبع المصاريف الشخصية — كل مستخدم يرى مصاريفه فقط.

## التثبيت

1. انسخ مجلد `masareefy` إلى `wp-content/plugins/`.
2. من لوحة التحكم → **الإضافات**، فعّل **مصاريفي**.
3. عند التفعيل تُنشأ تلقائيًا جدول `wp_masareefy_expenses` (مع بادئة موقعك).

## الخصوصية

- كل سجل مرتبط بـ `user_id` للمستخدم المسجّل.
- لا يمكن لأي مستخدم قراءة أو تعديل مصاريف مستخدم آخر.
- REST API وطبقة التخزين تفلتر دائمًا حسب `get_current_user_id()`.

## REST API

المسار الأساسي (يتطلب تسجيل دخول وصلاحية `read`):

```
/wp-json/masareefy/v1/expenses
```

| الطريقة | المسار | الوظيفة |
| --- | --- | --- |
| GET | `/expenses` | قائمة مصاريف المستخدم الحالي |
| POST | `/expenses` | إنشاء مصروف |
| GET | `/expenses/{id}` | عرض مصروف |
| PUT/PATCH | `/expenses/{id}` | تحديث مصروف |
| DELETE | `/expenses/{id}` | حذف مصروف |

## لوحة الإدارة

بعد التفعيل يظهر عنصر قائمة **مصاريفي** في لوحة التحكم — واجهة RTL مبدئية للتطوير القادم.

## شورت كود (مخطط)

```
[masareefy]
```

سيُستخدم لاحقًا لعرض واجهة المصاريف في الواجهة الأمامية للموقع.

## إلغاء التثبيت

عند **حذف** الإضافة (وليس مجرد تعطيلها) يُزال جدول `wp_masareefy_expenses` عبر `uninstall.php`.

## المتطلبات

- WordPress 6.0+
- PHP 7.4+
