# تحويل مصاريفي إلى إضافة WordPress

الهدف النهائي: نفس تجربة «مصاريفي» داخل ووردبريس كإضافة (Plugin).

## مبدأ التصميم الحالي (مهم)

كل منطق الحسابات والفلترة موجود في `src/core/` بدون اعتماد على React أو Next:

| ملف | دوره في البلجن لاحقًا |
| --- | --- |
| `types.ts` | نماذج البيانات |
| `money.ts` | تنسيق المبالغ |
| `date-range.ts` | فلاتر الفترات |
| `expense-filters.ts` | بحث/فرز/ترقيم |
| `analytics.ts` | الإحصاءات |
| `repository.ts` | عقد التخزين الموحّد |

التخزين الحالي في المتصفح (`LocalExpenseRepository`) ينفّذ نفس العقد.
في ووردبريس سنكتب فئة PHP بنفس الأسماء تقريبًا وتتعامل مع `wpdb`.

## مراحل البلجن (بعد اكتمال الويب)

1. إنشاء هيكل إضافة: `masareefy/masareefy.php`
2. جدول `wp_masareefy_expenses` بنفس الحقول
3. REST API أو Admin AJAX لـ CRUD
4. صفحة إعدادات للعملة والمنطقة الزمنية
5. Shortcode / Gutenberg Block لعرض الجدول والتقويم
6. تصدير/استيراد من النسخة الويب

أنت كصاحب المنتج لن تحتاج كتابة كود — المبرمج (Cursor) سيتولى التحويل عندما نصل لهذه المرحلة.
